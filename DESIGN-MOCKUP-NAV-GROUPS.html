交互规格

开合与关闭

  • 悬停约 120ms 延迟展开；点击切换开合。
  • 点击菜单项 = 切换视图并收起面板。
  • 点击面板外部、按 Esc、窗口 resize 时关闭。
  • 无障碍：aria-haspopup / aria-expanded / role=menu，键盘可达。

激活态与 badge

  • 组按钮沿用主 tab 同款激活语言：蓝字 + 2px 底边线，宽度不变（D3）。
  • 面板内当前项浅蓝底 + 右侧 ✓。
  • 最新文献未读数 badge 留在主 tab；收藏数显示在「文献库 ▾ 收藏文献」行内，>0 时组按钮亮小圆点。
  • nav-wrap 边缘渐隐 + 滚轮横滚兜底机制保留（D4），正常档位不触发。

决策点（D1–D4）

D1 · 分组结构推荐 A

A：3 主 tab + 文献库 / 统计·讨论 / 更多 三组（本 mockup 所示）。

B：仅 2 组更紧凑——文献库（收藏/关键词统计/文献推送）+ 更多（公共讨论/使用说明/管理中心），公共讨论被收进「更多」。

D2 · 账户入口推荐右侧胶囊

方案 1：账户名移到右侧用户胶囊，与「退出网页」相邻（本 mockup 所示）。

方案 2：账户入口留在「更多」下拉组内。

D3 · 组激活态推荐蓝字+底线

方案 1：组按钮 = 主 tab 同款蓝字 + 底边线，宽度不变；面板内打勾（本 mockup 所示）。

方案 2：组按钮文字切换为当前子项名（如「文献库 · 收藏文献」），方向感强但宽度抖动。

D4 · 横滚兜底推荐保留

方案 1：保留 nav-wrap 渐隐 + 滚轮横滚，极端窄窗口仍有退路，零风险。

方案 2：删除相关代码（main.jsx ~802–837 与样式），结构更简。
