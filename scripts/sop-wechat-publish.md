# 公众号日报 · 人工发布 SOP

> 适用：DESIGN-WECHAT-MP-DAILY.md 链路的最后一步（自动化只到草稿/成品，发布永远由人执行）。
> 前置：定时任务已产出当日 `data/wechat-drafts/<期号日>.{json,html}` 且探针 0 违规。

## 通用铁律

1. **发布前必须预览**：群发不可撤回、每天仅 1 次（订阅号，0 点重置不累积）。
2. **先发预览给自己手机**：确认排版、无错别字、速评无幻觉表述后再群发。
3. 发布时勾选平台「**AI 生成内容声明**」。
4. 当日 `data/daily-news/<昨日>.md` 缺失导致的资讯空板块是预期行为，不要临时手补旧闻。

## L0 · 网页端粘贴发布（无 AppSecret 配置时）

1. 浏览器打开 `data/wechat-drafts/<期号日>.html`。
2. `Ctrl+A` 全选 → `Ctrl+C` 复制（页面正文即发布内容，全内联样式，粘贴保真）。
3. 登录 `mp.weixin.qq.com` → 首页「新的创作」→ **图文消息** → 新建图文。
4. 正文编辑区 `Ctrl+V` 粘贴；检查：标题区/卡片底色/加粗数字是否保留。
5. 填写：
   - 标题：`电研新视界 日报｜<期号日>`（与正文 H1 一致，≤64 字节）
   - 摘要：从 `data/wechat-drafts/<期号日>.json` 的 `digest` 字段复制（≤60 字）
   - 封面：`assets/wechat-cover.png`（含当日日期；可 `node scripts/make-wechat-cover.mjs <期号日>` 重新生成）
   - 原文链接：`https://lhmktz.top`（「阅读原文」位）
6. 「保存为草稿」→ 预览（发管理员手机）→ 确认 → **群发**。
7. 回填：在 `data/wechat-drafts/` 同目录建 `<期号日>.published` 空文件标记已发（防止重发）。

## L1 · 订阅号助手 App 发布（已配草稿 API 后的日常路径）

1. 日报草稿在公众号「草稿箱」：定时任务自动写入（M4 实测通过后接入 prompt）；过渡期手动跑
   `node scripts/publish-wechat-draft.mjs --in data/wechat-drafts/<期号日>.json`
   （输出草稿 media_id；封面首次自动上传永久素材并缓存 `data/wechat-drafts/cover-thumb.json`）。
2. 手机打开「订阅号助手」App（管理员微信登录）→ 我发表的内容 → 草稿。
3. 打开当日日报 → 核对封面/摘要（API 写入值若缺，按 L0 第 5 步补）→ 预览到手机。
4. 确认无误 → **发表**（每天 1 次额度，注意 0 点重置）。
5. 回填 `.published` 标记同 L0 第 7 步。

## 异常处理

| 情形 | 处置 |
|---|---|
| 当日草稿未生成 | 会话里说「补跑公众号日报 YYYY-MM-DD」手动触发（prompt 同定时任务） |
| 素材已导出但渲染失败 | 按渲染器违规清单修正 issue JSON 后重跑（禁止手改 HTML） |
| 额度已用 / 发布后发现错误 | 订阅号群发不可撤回；次日日报开头更正，必要时删文重发占用次日额度 |
| 双档并存时的顺序 | 已配 L1 后：以 L1 为主，L0 仅作 API 故障兜底 |
