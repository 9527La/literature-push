# 电气前沿速递

> 面向电力系统与能源研究人员的文献速递、AI 研究速览、每日资讯、关键词分析、公共讨论和邮件推送网页。
>
> **使用范围：本项目只限于课题组内部使用，请勿外传，请勿用于商业用途。**

## 这个网页是什么

这个网页把多个电力与能源领域期刊的最新论文集中到一个入口，帮助你快速完成以下工作：

- 查看近期发表的论文标题、作者、期刊、日期、摘要、关键词和原文链接；
- 按期刊、日期、关键词、阅读状态和收藏状态筛选文献；
- 阅读中文标题和中文摘要，减少查阅外文论文的时间；
- 查看每篇文献的 AI 研究方向标注（15 个研究方向，卡片上以彩色标签显示）；
- 阅读「研究速览」：AI 生成的周报/月报与各研究方向专报，逐篇给出研究对象、研究方法与核心结论；
- 阅读「每日资讯」：自动汇总前一天的电力能源政策文件与重点新闻；
- 统计研究关键词的出现频次，观察研究主题和关键词之间的联系；
- 将感兴趣的论文收藏、标记为已读，并在多个设备之间同步个人设置；
- 订阅期刊并定时接收邮件文献推送；
- 在公共讨论区发布问题、建议和使用经验，与其他用户交流。

网页面向个人研究使用。文献内容来自公开可访问的学术信息，具体的出版信息和全文请以原文页面为准。

## 进入网页

### 第一次访问

1. 打开站点管理员提供的网页地址。
2. 在“输入网页通行证”页面输入站点通行证。
3. 验证通过后进入网页。

网页通行证只用于进入站点，与下面的个人账户不是同一套账号。管理员通行证可以打开“管理中心”，普通用户通行证用于日常浏览。通行证由站点管理员单独提供，README 不记录任何通行证或密码。

### 游客和个人账户的区别

输入网页通行证后，即可使用游客模式浏览公开内容。若希望保存自己的阅读、收藏、推送和讨论身份，请在“游客账户”页面注册或登录个人账户。

| 身份 | 可以做什么 | 说明 |
| --- | --- | --- |
| 游客 | 浏览文献、搜索、筛选、查看关键词统计、阅读公共讨论 | 不能保存阅读状态、收藏、推送设置，也不能发言、评论或点赞 |
| 个人账户 | 使用全部个人功能，参与公共讨论 | 用户名唯一；个人账户不等同于网页通行证 |
| 管理员 | 使用管理中心维护文献、翻译、用户和社区内容 | 只有管理员通行证可以进入管理中心 |

## 推荐使用流程

1. 进入网页后，打开“文献推送”，勾选需要关注的期刊并保存。
2. 在“最新文献”中使用搜索框和筛选条件定位论文。
3. 打开“游客账户”注册或登录个人账户，以保存已读、收藏和个性设置。
4. 在“我的账户”完善资料，并选择本机保存或远端同步方式。
5. 在“文献推送”填写邮箱、选择推送频率和邮件内容，保存后即可定时接收。
6. 在“公共讨论”设置发言名称，再发布主题或参与评论。

## 最新文献

“最新文献”是日常使用的主页面，默认只显示已经订阅的期刊。

### 搜索、筛选和排序

- 筛选面板默认打开，但在桌面端以浮动面板显示，不会长期占用文献列表宽度；点击“收起筛选”即可恢复完整阅读区域，需要时再点击“打开筛选”。
- 筛选面板内部的每条规则都可以单独展开或收起，首次打开时默认收起；已选条件会显示在“打开筛选”按钮旁。
- **搜索**：在顶部输入标题、作者、摘要或关键词，匹配内容会高亮显示。
- **期刊**：可同时选择多本期刊；期刊按出版社分组展示（IEEE 期刊 / 爱思唯尔期刊 / 中文期刊等），点击组名可展开或收起该组；同一筛选项内的多个选择按“或”匹配。
- **研究方向**：可按 AI 标注的研究方向多选筛选（如储能系统、电力市场与机制等），每个方向附文献计数；“其他/交叉”类文献不进入文献库列表，也不提供筛选入口。
- **关键词**：点击关键词标签，查看包含该关键词的文献。
- **时间范围**：填写开始日期和结束日期，限定论文发布日期。
- **仅未读**：只显示尚未标记为已读的论文。
- **仅收藏**：只显示自己收藏的论文。游客可以看到筛选项，但需要登录个人账户才能保存收藏。
- **排序**：支持最新优先、最早优先和按相关性排序。
- **清除筛选**：每个筛选分组右上角有独立的“清除”按钮，可单独重置该组条件；面板顶部提供“清除全部筛选”，一键恢复初始状态。

多个筛选条件同时使用时，条件之间按“且”匹配。例如同时选择期刊和“仅未读”，结果必须来自所选期刊并且尚未读过。

### 列表显示和文献详情

每篇文献卡片顶部有**期刊色标与 AI 研究方向标签**。方向由 AI 按标题、摘要与关键词自动标注（15 个研究方向，如储能系统、电力市场与机制、微电网与虚拟电厂等），点击标签可筛选该方向文献；管理员的改判永远优先于 AI 标注。少数暂未完成标注的文献不显示标签。

页面顶部的“显示内容”开关可以分别控制以下内容：

- 作者；
- 原文关键词；
- 原文摘要；
- 中文标题；
- 中文摘要（默认关闭；中文期刊不重复显示中文摘要，外文文献可手动开启）。

点击论文标题或查看按钮，可以打开详情窗口，查看 DOI、卷期、作者、关键词、摘要和原文链接。详情窗口还可以：

- 标记已读或取消已读；
- 收藏或取消收藏；
- 获取中文翻译；
- 一键复制 GB/T 7714 格式的引用条目（窗口顶部引用按钮），DOI 也可单独复制；
- 查看底部自动推荐的 3 篇“相关文献”（同研究方向、关键词相近），点击即可切换查看；
- 打开出版社或数据来源提供的原文页面。

### 页面加载和内容补全

已经保存的摘要、关键词和翻译会优先直接显示。只有缺少的字段才会在后台补全，因此切换期刊或筛选条件时，不需要重新等待已有内容。

页面提示中的含义如下：

- **数据库已载入**：当前内容已经保存，可以直接查看；
- **待补全**：这篇文献仍缺少摘要、关键词或翻译；
- **正在补全当前页面缺失内容**：后台正在处理缺失字段；
- **当前页面后台补全结果**：本次补全已经结束，可查看成功和失败数量。

如果某篇论文仍然没有摘要或中文摘要，可以在打开“中文摘要”显示开关后，点击论文卡片上的“获取摘要与中文翻译”“获取中文摘要”，或者请管理员在管理中心批量补全。中文期刊不需要重复获取中文摘要。翻译成功后会保存，之后其他用户打开同一内容时会优先使用已保存结果。

列表一次显示一批文献，滚动到列表底部后点击“继续显示下一批文献”即可查看后续内容。

页面右上角还会显示文献总量、未读、收藏，以及按首次进入数据库时间统计的最近一周和最近一月新增数量。

## 研究速览

「研究速览」由 AI 在每周日晚（月报为每月 1 日凌晨）基于当期入库文献自动生成，所有数字取自数据库统计：

- **三字段速评卡**：每篇文献一张卡片，固定给出**研究对象**（研究了什么）、**研究方法**（怎么做）、**核心结论**（得到什么），点击卡片直接打开文献详情；卡片配色与期刊色系一致（IEEE 蓝 / 爱思唯尔棕 / 中文青 / 其他灰）。
- **方向分组浏览**：总览页把本期文献按 15 个研究方向分组，默认全部展开，可用右上角按钮一键折叠/展开；每组显示篇数环比、本期主题一句话和 3 张速评卡预览，「查看该方向全部 N 篇」按本期时间窗列出完整清单。
- **方向专报**：点击方向 chips 进入单个方向的深度报告（主题聚类、逐篇速评、方法观察）。周报与月报均生成方向专报；月报的速评沿用当期各周周报已写内容，同一文献在不同期数之间的口径保持一致。
- **个性化方向切换**：方向 chips 支持拖拽排序与隐藏（存于本机浏览器），隐藏的方向不再出现在切换栏与分组浏览中。
- **历史回看**：顶部下拉可切换历史期数；点击期刊名可查看该刊最近文献，主题词可一键搜索。

速览为 AI 生成内容，推荐理由仅依据论文摘要撰写；发现结论与原文不符时请以原文为准。

## 每日资讯

「每日资讯」每天凌晨自动汇总**前一天**新出的电力能源政策文件与重点新闻：

- 左侧日期列表显示每天的政策/新闻条数，点击切换；日期很多时，可在左栏顶部输入框按日期片段查找（如输入 `2026-10` 或 `10-05`）；
- 正文按「概览 → 逐条详情」组织，点击概览条目可直达对应详情，每条附来源链接；
- 正文顶部可按“政策文件 / 重点新闻”分类筛选（分类附条数），也可在查找框中匹配当日资讯的标题与正文，配合“重置”一键清空；
- 当天无新政策时如实标注，不凑数。内容由 AI 辅助生成，重要信息请以官方原文为准。

## 收藏文献

登录个人账户后，点击文献卡片上的星标即可收藏。打开“收藏文献”页面可以：

- 新注册的个人账户会自动拥有“默认收藏夹”，首次收藏时会优先保存到该分组；
- 创建、重命名和删除收藏分组；
- 将每篇收藏文献放入指定分组，或保留在“未分组”；
- 为文献添加和修改阅读备注；
- 点击标题查看详情，或取消收藏。

收藏、分组和备注都按个人账户隔离，并保存在远端数据库中。同一账户在允许的登录设备上重新登录后，可以继续使用自己的收藏；其他账户不会看到这些内容。

## 摘要、关键词和翻译

### 摘要和关键词补全

部分文献来源只提供标题或基本书目信息，摘要、关键词可能暂时为空。遇到这种情况：

1. 在文献卡片或详情窗口点击补全按钮；或
2. 联系管理员在“管理中心”执行“补全摘要”或“补全关键词”。

管理员也可以直接使用“补全摘要和关键词”执行统一维护路径。系统会先补全摘要，再补全关键词，点一次就一直在后台处理到排空；连续没有进展时会有限停止，并在任务记录中保留剩余数量和失败原因，后续可再次复用该入口。

这三个入口（以及“一键翻译标题 / 摘要”）都是一次点击跑到排空，页面上会显示进度条、已处理 / 成功 / 剩余数量、处理速率和预计剩余时间；刷新页面后进度条会接着显示。需要中断时点“停止”，当前正在处理的那一篇结束后即停，已经补全的结果都会保留。同一时间只允许一个补全任务在跑，重复点击会提示已有任务在运行。

补全按固定顺序尝试出版社接口、Scopus、Crossref 和 Semantic Scholar API（OpenAlex 默认关闭，见下）。如果这些接口和直接抓取出版社页面都没有结果，系统才会启用**统一的浏览器兜底流程**（`server/web-fallback.js`）：

1. 按 `WEB_FALLBACK_SITES` 的顺序取候选站点（默认先走 DOI 解析后的出版社落地页，再走 Semantic Scholar 检索页）；
2. 全局单通道排队，两次请求之间至少间隔 `WEB_FALLBACK_REQUEST_INTERVAL_MS`（默认 12 秒），不会并发打同一个站点；
3. 用真实的 Edge/Chrome 无头浏览器渲染页面，这是纯 HTTP 抓不到的 Cloudflare / JS 挑战页的唯一解法；
4. 统一解析 JSON-LD、出版社专用字段和 `citation_*` / `og:*` 通用 meta；
5. **标题归一化后完全一致或 DOI 一致才认**，否则整条丢弃——避免把同刊的另一篇文章写成摘要；
6. 只补缺失字段，已经拿到的内容不会被覆盖。

任一站点失败、页面结构变化或校验不通过都会安全失败并记录到任务诊断里，不会写入相近论文或错误页面。兜底默认启用，可用 `WEB_FALLBACK_ENABLED=false` 关闭；浏览器路径用 `WEB_FALLBACK_BROWSER_EXECUTABLE` 指定（留空则自动查找 Edge 或 Chrome），单篇超时为 `WEB_FALLBACK_TIMEOUT_MS`。

**IEEE 现在优先走官方 API。** 已实测 Crossref、Semantic Scholar、OpenAlex、OpenAIRE、Europe PMC、Unpaywall 与 DOI 内容协商：这些免费接口对 IEEE 文献都只返回摘要（有的连摘要都没有），**没有一家提供作者关键词**；IEEE Xplore 的页面用纯 HTTP 直连只返回空的 202 响应。因此配置了 `IEEE_API_KEY` 之后，IEEE 的摘要与关键词改由官方接口（IEEE Xplore API）直接提供，拿不到时才退回上面的六步浏览器流程。

IEEE Xplore 的关键词分三类，系统按下面的顺序取舍（官方接口见 `server/ieee.js`，浏览器兜底见 `server/html-metadata.js`）：

| 类型 | 官方接口字段 | 说明 | 处理 |
| --- | --- | --- | --- |
| Author Keywords | `author_terms` | 作者自己填写 | **优先采用** |
| IEEE Keywords | `ieee_terms` | IEEE 受控词表，偶有跑偏 | 只在没有作者关键词时兜底 |
| Index Terms | `dynamic_index_terms` | 机器从正文抽取，一次 30 个 | **一律丢弃** |

不分类型地全取，会让一篇轨道交通论文的关键词里混进 `Electronic mail; TV; Radio access networks` 这类受控词。

#### IEEE API 的访问限制

IEEE Xplore API 注册档的额度约为 **200 次调用/天**、单次最多返回 200 条记录（具体以 developer.ieee.org 注册时展示的 Rate Limits 为准），而网关**不返回剩余额度响应头**，所以只能本地记账（见 `server/ieee.js`）：

| 环境变量 | 默认值 | 作用 |
| --- | --- | --- |
| `IEEE_ENABLED` | `true` | 只关掉 IEEE 而保留密钥，排查时用 |
| `IEEE_DAILY_CALL_LIMIT` | `180` | 每日调用上限，按 **UTC 日**切分，记在 `data/ieee-quota.json`；`0` 表示不限制 |
| `IEEE_REQUEST_INTERVAL_MS` | `1500` | 两次请求的最小间隔；所有 IEEE 请求走同一条串行通道，不会并发突发 |

达到上限后当天不再发 IEEE 请求，自动降级到 Scopus / Crossref / Semantic Scholar / 浏览器兜底；收到 429 会直接把当天额度打满，避免继续被拒。

> OpenAlex 自 2026 年 2 月起要求所有请求带密钥并按日额度计费，本项目没有可用密钥时每次调用都会返回“额度不足”，采集与补全都在白跑，因此**默认关闭**（`OPENALEX_ENABLED`，默认 `false`）。拿到密钥后设置 `OPENALEX_ENABLED=true`、`OPENALEX_API_KEY=<密钥>`，并在 `PUBLIC_DATA_SOURCES` 中加回 `openalex` 即可恢复。

补全完成后，摘要和关键词会回到文献列表、详情窗口和关键词统计中。若来源页面不可访问或没有公开字段，系统会保留原有内容，并在任务结果中显示失败数量，管理员可以稍后重试。

### 翻译

文献详情窗口支持“译为中文”。翻译内容仅包括英文标题和英文摘要；中文文献不会被翻译成英文，关键词也不会进入翻译队列。列表中的中文标题、中文摘要也可以通过缺失提示直接获取。

翻译结果会保存到站点内容中。后续用户优先读取已经保存的翻译，只有没有对应结果时才会再次发起翻译请求。这样可以减少重复等待，并保持不同用户看到的翻译一致。

批量补全时，系统会把缺少的标题和摘要统一处理，并把结果按文献和字段写回缓存。摘要过长会自动分段后再拼接；已有字段不会重复请求，也不会把关键词加入翻译队列。翻译服务暂时不可用时，系统会自动尝试备用服务，并在任务记录中保留成功、失败和剩余数量。

管理中心的批量翻译不需要设置每轮篇数：开跑前系统会抽样估算队列需要多少字符，再与翻译渠道的**剩余额度**比较，自动决定这次能翻多少篇，额度不足时停在额度允许处并说明原因。单个请求的长度由分包逻辑控制（腾讯云每请求最多 10 条 / 1800 字符，百度按其上限自动适配），不会出现超大请求。

当前翻译渠道为 **腾讯云 → 百度**：两家都设有本地月度硬上限（`TENCENT_MONTHLY_CHAR_BUDGET`、`BAIDU_MONTHLY_CHAR_LIMIT`），触及即停止调用，不会产生意外费用。火山引擎、LibreTranslate、MyMemory 已暂停，不在自动链路内；百度没有额度查询接口，管理中心显示的百度用量是本系统的本地记账，并已标注。

## 关键词统计

“关键词统计”用于查看一段时间内、一本或多本期刊中的研究关键词分布。

使用步骤：

1. 选择期刊，或保留“全部期刊”。
2. 设置开始日期和结束日期。
3. 点击“统计”。
4. 使用关键词搜索框查找具体词语。

统计结果提供三种视图：

- **列表**：按出现次数排列关键词，并显示每个关键词对应的文献数量；
- **词云**：用文字大小直观展示高频关键词；
- **共现**：查看经常出现在同一篇文献中的关键词组合。

点击关键词后，右侧会列出包含该关键词的文献。点击文献卡片可以打开完整详情、标记已读、收藏或访问原文。

如果统计结果缺少关键词，通常是相关文献尚未完成关键词补全；管理员完成补全后，重新点击“统计”即可更新结果。

## 文献推送

文献推送设置需要登录个人账户。游客可以浏览设置页面，但不能保存自己的邮箱、订阅和推送计划。

### 设置接收邮箱

1. 打开“文献推送”。
2. 在“我的周报邮箱”中填写接收地址。
3. 点击“保存”。
4. 如需确认地址可用，点击“发送测试邮箱”。

测试邮件或正式推送未成功时，请先确认邮箱地址，再联系站点管理员检查邮件服务状态。

### 设置自动推送

打开“启用自动推送”后，可以设置：

- **推送频率**：每天、每周或每月；
- **发送时间**：选择小时和分钟；每周推送还需选择星期，每月推送还需选择日期；
- **邮件内容**：附件文件、摘要、关键词、翻译可以分别开启或关闭；
- **推送期刊范围**：选择指定期刊，或直接使用全部已订阅期刊；
- **推送研究方向**：选择后只推送所选方向（“其他”默认不推送）；邮件正文会按研究方向分组展示，分组顺序与设置页点选顺序一致（方向标签上有顺序编号，取消后重新点选即可调整）。

点击“保存推送设置”后，计划才会生效。推送摘要会按照设定的时间范围整理最新文献；“立即发送”可以不等待下一个计划时间，马上发送一封当前摘要邮件。

## 公共讨论

“公共讨论”是公开展示的交流区域，适合发布使用建议、问题和研究信息。

### 游客

游客可以阅读主题、评论和点赞数量，但不能发布主题、评论或点赞。

### 个人账户

登录个人账户后，先在编辑框中设置发言名称，再进行以下操作：

- 发起讨论主题；
- 评论已有主题；
- 对主题或评论点赞；
- 修改自己的公开发言名称。

系统会为每个个人账户生成稳定的公开标签，用于区分不同发言者。用户可以自行设置显示名称；登录 IP 只用于会话限制，不会作为公开讨论标签显示。每个账户每小时最多发起一个新主题。

### 管理员

管理员可以公开回复主题、结束不再需要继续的主题，以及删除不合适的主题或评论。结束主题后，普通用户不能继续评论。

讨论内容面向站点访问者公开展示，不会自动通过邮件转发，请不要发布密码、令牌、个人联系方式或其他敏感信息。

## 我的账户

### 注册和登录

在“游客账户”页面切换到“注册个人账户”，填写唯一用户名和密码即可注册。注册成功后会自动登录。

登录时可以选择：

- **记住密码**：在当前浏览器保存用户名和密码，方便下次填写；
- **自动登录**：在同一 IP 下优先恢复有效会话，打开网页后无需重复输入。

请只在个人或可信设备上启用“记住密码”。在公共电脑上使用完毕后，应退出个人账户并退出网页。

### 账户资料

登录后可在“我的账户”填写和保存：

- 姓名；
- 入学年份；
- 学历；
- 周报接收邮箱。

### 个性设置保存与同步

个性设置包括文献筛选条件、列表显示开关、订阅期刊和推送配置。可以选择：

- 自动保存在本机；
- 手动保存到本机或从本机载入；
- 上传到个人账户，供其他设备载入；
- 从个人账户载入已经保存的设置。

阅读状态、收藏状态和讨论身份也属于个人账户数据。网页通行证变化不会替换个人账户，个人账户退出也不会自动退出网页通行证；需要离开站点时，请点击“退出网页”。

## 账户规则与权限

- 每个个人账户同一时间只能在一个 IP 上保持登录；从另一个 IP 登录后，原 IP 的会话会失效。
- 同一 IP 可以登录多个个人账户。
- 全站最多同时保持 20 个活跃 IP 的个人账户会话。
- 网站最多允许注册 40 个个人账户。
- 个人账户没有管理员权限；管理功能由管理员网页通行证控制。
- 目前没有自助找回个人账户密码的入口。忘记密码时，请联系站点管理员处理。

## 管理中心

管理中心只对管理员开放，普通用户和游客不会看到入口。

### 数据维护

管理员可以按需执行以下任务：

- **刷新文献数据**：获取期刊中的最新文献；
- **补全摘要**：处理缺少原文摘要的文献；
- **补全关键词**：处理缺少原文关键词的文献；
- **翻译标题**：批量处理缺少中文标题的文献；
- **翻译摘要**：批量处理缺少中文摘要的文献。

### 任务记录

每次任务都会显示任务类型、开始时间和结果。新增内容分别统计为：

- 新增文献数量；
- 新增摘要数量；
- 新增关键词数量；
- 新增翻译数量。

如果任务中有内容获取失败，还会分别显示文献、摘要、关键词和翻译的失败数量，以及任务完成后仍待补全的摘要和关键词数量。管理员可以据此判断是继续重试补全，还是直接通过原文页面查看。

翻译任务还会显示标题/摘要翻译单元数量和实际 API 请求次数，便于确认批量请求是否生效。部分成功时只重试未完成的字段，失败原因会保留在任务记录中。

### 用户管理

管理员可以在“用户管理”中：

- 新增普通用户，并设置初始用户名、密码、显示名称和邮箱；
- 查看用户角色、资料和注册时间；
- 删除普通用户。

删除用户前需要二次确认。删除后，该用户的登录会话、个人设置、阅读/收藏状态和讨论关联数据也会一起清理；最高管理员账户受到保护，不能从这里删除。

### 内容概览

管理中心还会显示文献总量、摘要和翻译覆盖情况、注册账户数量、讨论数量以及各期刊的文献分布，方便管理员判断内容是否完整。

## 常见问题

### 为什么打开网页后仍然看不到内容？

必须先输入有效的网页通行证。若通行证已过期或站点管理员更换了通行证，请重新获取最新通行证。

### 为什么不能收藏或标记已读？

这些操作属于个人数据功能，游客只能浏览。请到“游客账户”登录个人账户后再操作。

### 为什么切换期刊后仍然看到“补全”提示？

已保存的内容会立即展示，提示只针对当前页面缺少的摘要、关键词或翻译。后台补全结束后，页面会更新结果；不需要重复等待已经存在的内容。

### 为什么翻译没有马上出现？

翻译需要等待处理，或原文暂时没有可翻译的摘要。可以稍后重试；如果管理员批量任务也报告失败，请通过原文链接查看论文。

### 为什么从另一台设备登录后，原来的设备退出了？

同一个个人账户同一时间只能绑定一个 IP。请在当前设备重新登录，或者先在原设备退出账户。

### 个人账户和网页通行证是不是同一个账号？

不是。网页通行证负责进入站点，个人账户负责保存个人数据和参与讨论，两者可以独立使用。

## 自托管部署（管理员）

本节面向自行部署本系统的管理员；日常使用者可以跳过。

### 环境要求与启动

- Node.js ≥ 22（依赖原生 `node:sqlite`）；
- `npm install` 安装依赖，`npm run build` 构建前端到 `dist/`，`npm start` 启动服务（默认端口 4177，同时提供 API 与构建产物）；
- 开发模式用 `npm run dev`（后端 4177 + Vite 5173 代理）。

### 必填环境变量

服务在仓库根目录读取 `.env`（模板见 `.env.example`）。以下三项**没有默认值，缺失时服务拒绝启动**——硬编码默认值曾在公开 git 历史中泄露，已于 2026-10-01 移除：

| 变量 | 说明 |
| --- | --- |
| `ADMIN_PASSPORT` | 管理员网页通行证（进入站点 + 打开管理中心） |
| `USER_PASSPORT` | 普通用户网页通行证 |
| `SUPER_ADMIN_USERNAME` | 最高管理员个人账户用户名 |

其余变量均为可选或带安全默认值，覆盖数据源密钥（IEEE / Elsevier / 翻译服务）、邮件 SMTP、推送计划等，逐项说明见 `.env.example` 注释。**任何通行证、密钥只保存在 `.env`（已被 .gitignore 排除），不要写进代码或文档。**

### 数据与维护

- 数据库为 `data/literature.sqlite`（SQLite，含文献、用户账户、会话等），`data/` 目录已被 .gitignore 排除，随部署独立备份；
- Windows 生产环境的计划任务、看门狗与部署脚本见 `DEPLOY.md`；
- AI 批量作业（研究方向分类、周报/月报/方向专报）由仓库根目录 `RUNBOOK-AI-JOBS.md` 与 `.workbuddy/skills/literature-ai-jobs/` 描述，是独立的定时执行流程，不参与服务进程。
