# 电气前沿速递

> 面向电力系统与能源研究人员的文献速递、AI 研究速览、每日资讯、关键词分析、公共讨论和邮件推送网页。
>
> **使用范围：本项目只限于课题组内部使用，请勿外传，请勿用于商业用途。**

## 这个网页是什么

这个网页把多个电力与能源领域期刊的最新论文集中到一个入口，帮助你快速完成以下工作：

- 查看近期发表的论文标题、作者、期刊、日期、摘要、关键词和原文链接；
- 按期刊、日期、关键词、阅读状态和收藏状态筛选文献；
- 阅读中文标题和中文摘要，减少查阅外文论文的时间；
- 查看每篇文献的 AI 研究方向标注（15 个研究方向，卡片上以彩色标签显示）；
- 阅读「研究速览」：AI 生成的周报/月报与各研究方向专报，逐篇给出研究对象、研究方法与核心结论；
- 使用「卡片阅读」把一批文献变成一张张卡片逐条翻阅：速评 / 中文摘要 / 原文三种版本随时切换，阅读中即可收藏、标记已读、记备注、复制引用；
- 阅读「每日资讯」：自动汇总前一天的政策、标准与重点新闻；
- 统计研究关键词的出现频次，观察研究主题和关键词之间的联系；
- 将感兴趣的论文收藏、标记为已读，并在多个设备之间同步个人设置；
- 定时接收邮件文献推送（可按期刊与研究方向偏好定制）；
- 在公共讨论区发布问题、建议和使用经验，与其他用户交流。

网页面向个人研究使用。文献内容来自公开可访问的学术信息，具体的出版信息和全文请以原文页面为准。

## 进入网页

### 第一次访问

1. 打开站点管理员提供的网页地址。
2. 在“输入网页通行证”页面输入站点通行证。
3. 验证通过后进入网页。

网页通行证只用于进入站点，与下面的个人账户不是同一套账号。管理员通行证可以打开“管理中心”，普通用户通行证用于日常浏览。通行证由站点管理员单独提供，README 不记录任何通行证或密码。

### 游客和个人账户的区别

输入网页通行证后，即可使用游客模式浏览公开内容。若希望保存自己的阅读、收藏、推送和讨论身份，请在“游客账户”页面注册或登录个人账户。

| 身份 | 可以做什么 | 说明 |
| --- | --- | --- |
| 游客 | 浏览文献、搜索、筛选、查看关键词统计、阅读公共讨论 | 不能保存阅读状态、收藏、推送设置，也不能发言、评论或点赞 |
| 个人账户 | 使用全部个人功能，参与公共讨论 | 用户名唯一；个人账户不等同于网页通行证 |
| 管理员 | 使用管理中心维护文献、翻译、用户和社区内容 | 只有管理员通行证可以进入管理中心 |

## 推荐使用流程

首次访问会自动弹出「新手教程」，跟着走一遍（当前 51 步，约 3 分钟）就能熟悉全部功能；跳过或中断后，可在“使用说明”页点“重新体验新手教程”重看。

1. 进入网页后，打开“文献推送”，勾选需要关注的期刊并保存。
2. 在“最新文献”中使用搜索框和筛选条件定位论文。
3. 打开“游客账户”注册或登录个人账户，以保存已读、收藏和个性设置。
4. 在“我的账户”完善资料，并选择本机保存或远端同步方式。
5. 在“文献推送”填写邮箱、选择推送频率和邮件内容，保存后即可定时接收。
6. 在“公共讨论”设置发言名称，再发布主题或参与评论。

## 新手教程

首次访问站点时自动弹出「新手教程」，一步步带你认识整个站点。教程会把页面上真正要点的按钮与区域用聚光灯高亮出来，跟着提示操作即可。

覆盖顺序：文献库与检索筛选 → 卡片阅读（选范围 → 生成目录 → 开始阅读 → 翻页 / 切换版本 / 目录抽屉 / 备注）→ 研究速览（页面结构、方向分组、三段式速评卡、方向专报与来源期刊筛选、卡片阅读入口）→ 每日资讯 → 收藏文献 → 关键词统计 → 文献推送（邮箱、频率、发送时间、邮件内容、期刊范围、研究方向）→ 公共讨论 → 账户与个性设置。

几点说明：

- **可以自己点，也可以点“下一步”**：需要操作的步骤，直接点“下一步”时教程会替你完成那一步的真实点击（打开筛选面板、生成文献目录、开始卡片阅读等），页面状态不会错位。
- **需要先进入某个界面的步骤，教程会自己打开**：例如“来源期刊筛选”只在方向专报里才有，教程会先替你切到方向专报；推送设置默认停在概览，教程会先进入编辑状态。
- **不适用或打不开的步骤会自动跳过，并写明原因**：例如未登录个人账户时会跳过“文献推送”一段；卡片阅读被关闭（例如按了 `Esc`）时，教程会先自动替你重新打开，仍打不开才跳过阅读器内的步骤。
- **`Esc` 的归属**：弹窗、目录抽屉或卡片阅读打开时，`Esc` 交给该界面（关闭它）；没有这些界面打开时，`Esc` 退出教程。
- **想重看**：打开“使用说明”页点“重新体验新手教程”。首次弹出过一次后不再自动弹出（记在本机浏览器里）。

## 最新文献

“最新文献”（文献库）是日常使用的主页面，覆盖站点收录的全部期刊。

### 搜索、筛选和排序

- 筛选面板默认收起，文献库首屏完整展示文献列表；点击“打开筛选”展开浮动面板，不会长期占用阅读区域。
- 面板内部的每个筛选分组（搜索 / 期刊 / 研究方向 / 时间范围 / 筛选 / 关键词 / 排序）默认也是收起状态，点击组名逐个展开，已选条件会显示在“打开筛选”按钮旁。
- **搜索**：在顶部输入标题、作者、摘要或关键词，匹配内容会高亮显示。
- **期刊**：可同时选择多本期刊；期刊按出版社分组展示（IEEE 期刊 / 爱思唯尔期刊 / 中文期刊等），点击组名可展开或收起该组；同一筛选项内的多个选择按“或”匹配。
- **研究方向**：可按 AI 标注的研究方向多选筛选（如储能系统、电力市场与机制等），每个方向附文献计数；“其他/交叉”类文献不进入文献库列表，也不提供筛选入口。
- **关键词**：点击关键词标签，查看包含该关键词的文献。
- **时间范围**：填写开始日期和结束日期，限定论文发布日期。
- **仅未读**：只显示尚未标记为已读的论文。
- **仅收藏**：只显示自己收藏的论文。游客可以看到筛选项，但需要登录个人账户才能保存收藏。
- **排序**：支持最新优先、最早优先和按相关性排序。
- **清除筛选**：每个筛选分组右上角有独立的“清除”按钮，可单独重置该组条件；面板顶部提供“清除全部筛选”，一键恢复初始状态。
- **工具栏快捷筛选**：工具栏右侧提供「时间范围」（近 7 日 / 近 30 日 / 本月）与「阅读状态」（全部 / 未读 / 已读），与筛选面板共用同一套条件、双向联动；已生效的筛选会在列表上方以摘要条提示，可一键清除。
- **卡片阅读入口**：工具栏「打开筛选」右侧的“卡片阅读”按钮进入卡片阅读模式（见下文「卡片阅读」）。

多个筛选条件同时使用时，条件之间按“且”匹配。例如同时选择期刊和“仅未读”，结果必须来自所选期刊并且尚未读过。

### 列表显示和文献详情

每篇文献卡片顶部有**期刊色标与 AI 研究方向标签**。方向由 AI 按标题、摘要与关键词自动标注（15 个研究方向，如储能系统、电力市场与机制、微电网与虚拟电厂等），点击标签可筛选该方向文献；管理员的改判永远优先于 AI 标注。少数暂未完成标注的文献不显示标签。

页面顶部的“显示内容”开关可以分别控制以下内容：

- 作者；
- 原文关键词；
- 原文摘要；
- 中文标题；
- 中文摘要（默认关闭；中文期刊不重复显示中文摘要，外文文献可手动开启）。

点击论文标题或查看按钮，可以打开详情窗口，查看 DOI、卷期、作者、关键词、摘要和原文链接。详情窗口还可以：

- 标记已读或取消已读；
- 收藏或取消收藏；
- 获取中文翻译；
- 一键复制 GB/T 7714 格式的引用条目（窗口顶部引用按钮），DOI 也可单独复制；
- 查看底部自动推荐的 3 篇“相关文献”（同研究方向、关键词相近），点击即可切换查看；
- 打开出版社或数据来源提供的原文页面。

### 页面加载和内容浏览

文献库展示的全部内容（标题、作者、摘要、关键词、中文标题与中文摘要）都来自站点数据库，由管理员统一采集和维护，打开即可直接阅读，无需等待补全。

列表一次显示一批文献，滚动到列表底部后点击“继续显示下一批文献”即可查看后续内容。列表上方的“共 N 篇文献”始终是符合当前筛选条件的全部文献数量，与已加载的条数无关。

页面右上角还会显示文献总量、未读、收藏，以及按首次进入数据库时间统计的最近一周和最近一月新增数量。

## 研究速览

「研究速览」由 AI 在每周日晚（月报为每月 1 日凌晨）基于当期入库文献自动生成，所有数字取自数据库统计：

- **三字段速评卡**：每篇文献一张卡片，固定给出**研究对象**（研究了什么）、**研究方法**（怎么做）、**核心结论**（得到什么），点击卡片直接打开文献详情；卡片配色与期刊色系一致（IEEE 蓝 / 爱思唯尔棕 / 中文青 / 其他灰）。
- **方向分组浏览**：总览页把本期文献按 15 个研究方向分组，默认全部展开，可用右上角按钮一键折叠/展开；每组显示篇数环比、本期主题一句话和 3 张速评卡预览，组头显示该组期刊构成（期刊缩写色标），「查看该方向全部 N 篇」按本期时间窗列出完整清单。
- **方向专报**：点击方向 chips 进入单个方向的深度报告。周报方向专报为逐篇速评结构；月报方向专报按**主题聚类（专题）**组织，聚类头可展开 / 收起，聚类内速评卡默认先显示一行、点“继续加载全部”查看其余条目。月报的速评沿用当期各周周报已写内容，同一文献在不同期数之间的口径保持一致。
- **卡片阅读入口**：每个方向分组底部、方向专报信息条右侧、以及每个主题聚类底部都提供“卡片阅读 · N 篇”，按该范围逐条阅读。
- **来源期刊筛选**：方向专报信息条中的期刊 chips 可点选隐藏 / 显示该来源的速评卡（仅影响当前报告的浏览，不改变数据）。
- **个性化方向切换**：方向 chips 支持拖拽排序与隐藏（存于本机浏览器），隐藏的方向不再出现在切换栏与分组浏览中。
- **历史回看**：顶部可在「一周速览 / 月度趋势」之间切换，并选择历史期数；点击期刊名可查看该刊最近文献，主题词可一键搜索。

速览为 AI 生成内容，推荐理由仅依据论文摘要撰写；发现结论与原文不符时请以原文为准。

## 卡片阅读

「卡片阅读」把一批文献变成一张张卡片，逐条快速翻阅，免去反复开关详情弹窗；阅读中即可收藏、标记已读、记备注和复制引用。

### 进入与选择范围

两种进入方式：

1. **文献库工具栏**：「打开筛选」右侧的“卡片阅读”按钮；
2. **研究速览**：方向分组底部 / 方向专报信息条 / 主题聚类底部的“卡片阅读 · N 篇”。

进入后先确定阅读范围，两种方式任选：

- **按速览期**：周报 / 月报 → 期次 → 研究方向 → 专题（主题聚类）；适合“把这一期这个方向读一遍”。按速览期读的是该方向的 AI 速评，因此**本期没有生成速评的方向会置灰并标注“无速评”**，不可选择（换一个有速评的方向，或改用“自定义筛选”）。
- **自定义筛选**：来源期刊（多选）/ 研究方向（多选）/ 时间范围 / 阅读状态 / 排序 / 数量上限（50 · 100 · 200 · 自定义 1–300 · 无上限）。

确定后点击“生成文献目录”，先看到目录清单（标题、期刊、日期、已读状态），确认无误再点“开始卡片阅读”；阅读中可随时“返回调整”重选范围。

若目录为空（筛选条件过窄），页面会说明原因并给出“重置条件并重新生成”的一键放宽入口；卡片内容加载失败时会提示“文献内容加载失败，请检查网络后重试”，可点“重新加载”或“跳过这一条”。

### 三种卡片版本

| 版本 | 内容 | 适用 |
| --- | --- | --- |
| 速评版 | 研究对象 / 研究方法 / 核心结论 | 快速把握一篇文献做了什么 |
| 中文摘要版 | 完整中文摘要（可展开英文原文对照） | 需要看完整摘要时 |
| 原文版 | 作者 + 英文摘要 | 核对原文表述 |

顶栏或键盘 `1 / 2 / 3` 切换版本，默认版本会自动记忆；摘要与原文版为宽幅卡片，长摘要一屏可见。

### 阅读中的操作

- **翻页与进度**：`←` `→`（或空格）翻页；顶部进度条可点击 / 拖动跳转到任意位置，右侧显示“第 N / M 条”。
- **读即标记**（默认开启）：向下翻页时自动把新条目标记为已读；“跳过已读”开启后翻页自动跳过已读文献。
- **断点续读**：同一范围再次打开时，自动回到上次读到的位置并提示。
- **目录抽屉**（顶栏列表按钮或 `D`）：查看全批清单、点击序号直达；可在阅读中改范围（仅未读 / 仅有速评 / 按期刊筛选）；底部“读完本批”可一键把本批剩余未读标记为已读（需二次确认，超过 300 篇请先缩小范围）。
- **相关文献**：卡片底部列出 3 篇相关文献，点击即可跳转；若不在本批，会自动接在当前条之后，形成连续阅读链。
- **卡片内操作**：收藏（`F`）、标记已读（`R`）、复制 GB/T 7714 引用（`C`）、添加备注（`N`，保存到收藏备注，未收藏时会先自动收藏）；`Esc` 退出。

### 分享直达

文献库的卡片阅读会写入地址 `#feed?reader=1`，可加入书签，或把链接发给他人直接进入卡片阅读。

速评版内容来自每周 AI 速评（随周报生成）；未被速评覆盖的文献会提示切换到中文摘要版查看完整摘要。收藏、已读与备注属于个人账户数据，游客只能浏览，不能保存。

## 每日资讯

「每日资讯」每天凌晨自动汇总**前一天**新出的政策、标准与重点新闻：

- 左侧日期列表显示每天的政策/新闻条数，点击切换；日期很多时，点击左栏「筛选日期」展开筛选框，自主选择开始 / 结束年月日（或只填一端做开区间），列表即时按范围过滤，筛选生效时可一键清除；
- 正文按「概览 → 逐条详情」组织，点击概览条目可直达对应详情，每条附来源链接；
- 正文顶部可按“政策标准 / 重点新闻”分类筛选（分类附条数），也可在查找框中匹配当日资讯的标题与正文，配合“重置”一键清空；
- 当天无新政策时如实标注，不凑数。内容由 AI 辅助生成，重要信息请以官方原文为准。

## 收藏文献

登录个人账户后，点击文献卡片上的星标即可收藏（首次收藏可选择分组）。打开“收藏文献”页面可以：

- 以与文献库一致的色系卡片浏览收藏：每张卡片左上角是期刊身份条（期刊色徽章 + 刊名），右上角是 AI 研究方向标签与收录日期；
- 创建、重命名和删除收藏分组（左侧分组列表，自定义分组的重命名 / 删除按钮常驻显示）；
- 将每篇收藏文献放入指定分组，或保留在“未分组”；
- 为文献添加和修改阅读备注（默认折叠为一行预览，点击展开编辑；卡片阅读中记的备注也会同步到这里）；
- 用顶部工具条做轻筛选与排序：按来源期刊、研究方向筛选，切换“最近收藏 / 出版日期”排序，显示“显示 N / 共 M 篇”，可一键“全部显示”；
- 点击标题查看详情，或点击右上角星标取消收藏。

收藏、分组和备注都按个人账户隔离，并保存在远端数据库中。同一账户在允许的登录设备上重新登录后，可以继续使用自己的收藏；其他账户不会看到这些内容。

## 摘要、关键词和翻译

文献的摘要、关键词、中文标题与中文摘要由管理员在后台统一采集、补全和翻译后存入数据库；浏览时直接展示已有内容，页面上没有手动补全入口。

如果某篇文献缺少摘要或中文翻译，可以通过详情窗口的原文链接查阅原文，或联系管理员在“管理中心”执行批量补全与批量翻译。补全按出版社官方接口优先的顺序多源尝试；翻译由腾讯云 / 百度双渠道自动互备，月度额度受控。所有补全与翻译结果全部入库，全站用户共享同一份内容，同一篇文献不会被重复处理。

## 关键词统计

“关键词统计”用于查看一段时间内、一本或多本期刊中的研究关键词分布。

使用步骤：

1. 选择期刊，或保留“全部期刊”。
2. 设置开始日期和结束日期。
3. 点击“统计”。
4. 使用关键词搜索框查找具体词语。

统计结果提供三种视图：

- **列表**：按出现次数排列关键词，并显示每个关键词对应的文献数量；默认显示前 100 个，底部“显示更多”可继续展开（关键词很多时页面打开更快）；
- **词云**：用文字大小直观展示高频关键词；
- **共现**：查看经常出现在同一篇文献中的关键词组合。

点击关键词后，右侧会列出包含该关键词的文献（一次 100 条，底部“加载更多”继续拉取）。点击文献卡片可以打开完整详情、标记已读、收藏或访问原文。

如果统计结果缺少关键词，通常是相关文献尚未完成关键词补全；管理员完成补全后，重新点击“统计”即可更新结果。

## 文献推送

文献推送设置需要登录个人账户。游客可以浏览设置页面，但不能保存自己的邮箱和推送计划。

### 设置接收邮箱

1. 打开“文献推送”。
2. 在“我的周报邮箱”中填写接收地址。
3. 点击“保存”。
4. 如需确认地址可用，点击“发送测试邮箱”。

测试邮件或正式推送未成功时，请先确认邮箱地址，再联系站点管理员检查邮件服务状态。

### 设置自动推送

打开“启用自动推送”后，可以设置：

- **推送频率**：每天、每周或每月；
- **发送时间**：选择小时和分钟；每周推送还需选择星期，每月推送还需选择日期；
- **邮件内容**：附件文件、摘要、关键词、翻译可以分别开启或关闭；
- **推送期刊范围**：选择指定期刊，或直接使用全部期刊；
- **推送研究方向**：选择后只推送所选方向（“其他”默认不推送）；邮件正文会按研究方向分组展示，分组顺序与设置页点选顺序一致（方向标签上有顺序编号，取消后重新点选即可调整）。

点击“保存推送设置”后，计划才会生效。推送摘要会按照设定的时间范围整理最新文献；“立即发送”可以不等待下一个计划时间，马上发送一封当前摘要邮件。

除邮件外，站点内容还会同步通过微信公众号“电气前沿速递”每日推送（关注后即可接收），与邮件推送并行、互不影响。

## 公共讨论

“公共讨论”是公开展示的交流区域，适合发布使用建议、问题和研究信息。

### 游客

游客可以阅读主题、评论和点赞数量，但不能发布主题、评论或点赞。

### 个人账户

登录个人账户后，先在编辑框中设置发言名称，再进行以下操作：

- 发起讨论主题；
- 评论已有主题；
- 对主题或评论点赞；
- 修改自己的公开发言名称。

系统会为每个个人账户生成稳定的公开标签，用于区分不同发言者。用户可以自行设置显示名称；登录 IP 只用于会话限制，不会作为公开讨论标签显示。每个账户每小时最多发起一个新主题。

### 管理员

管理员可以公开回复主题、结束不再需要继续的主题，以及删除不合适的主题或评论。结束主题后，普通用户不能继续评论。

讨论内容面向站点访问者公开展示，不会自动通过邮件转发，请不要发布密码、令牌、个人联系方式或其他敏感信息。

## 我的账户

### 注册和登录

在“游客账户”页面切换到“注册个人账户”，填写唯一用户名和密码即可注册。注册成功后会自动登录。

登录时可以选择：

- **记住密码**：在当前浏览器保存用户名和密码，方便下次填写；
- **自动登录**：在同一 IP 下优先恢复有效会话，打开网页后无需重复输入。

请只在个人或可信设备上启用“记住密码”。在公共电脑上使用完毕后，应退出个人账户并退出网页。

### 账户资料

登录后可在“我的账户”填写和保存：

- 姓名；
- 入学年份；
- 学历；
- 周报接收邮箱。

### 个性设置保存与同步

个性设置包括文献筛选条件、列表显示开关和推送配置。可以选择：

- 自动保存在本机；
- 手动保存到本机或从本机载入；
- 上传到个人账户，供其他设备载入；
- 从个人账户载入已经保存的设置。

阅读状态、收藏状态和讨论身份也属于个人账户数据。网页通行证变化不会替换个人账户，个人账户退出也不会自动退出网页通行证；需要离开站点时，请点击“退出网页”。

## 账户规则与权限

- 每个个人账户同一时间只能在一个 IP 上保持登录；从另一个 IP 登录后，原 IP 的会话会失效。
- 同一 IP 可以登录多个个人账户。
- 全站最多同时保持 20 个活跃 IP 的个人账户会话。
- 网站最多允许注册 100 个个人账户。
- 个人账户没有管理员权限；管理功能由管理员网页通行证控制。
- 目前没有自助找回个人账户密码的入口。忘记密码时，请联系站点管理员处理。

## 管理中心

管理中心只对管理员开放，普通用户和游客不会看到入口。

### 数据维护

管理员可以按需执行以下任务：

- **刷新文献数据**：获取期刊中的最新文献；
- **补全摘要**：处理缺少原文摘要的文献；
- **补全关键词**：处理缺少原文关键词的文献；
- **翻译标题**：批量处理缺少中文标题的文献；
- **翻译摘要**：批量处理缺少中文摘要的文献。

### 任务记录

每次任务都会显示任务类型、开始时间和结果。新增内容分别统计为：

- 新增文献数量；
- 新增摘要数量；
- 新增关键词数量；
- 新增翻译数量。

如果任务中有内容获取失败，还会分别显示文献、摘要、关键词和翻译的失败数量，以及任务完成后仍待补全的摘要和关键词数量。管理员可以据此判断是继续重试补全，还是直接通过原文页面查看。

翻译任务还会显示标题/摘要翻译单元数量和实际 API 请求次数，便于确认批量请求是否生效。部分成功时只重试未完成的字段，失败原因会保留在任务记录中。

### 用户管理

管理员可以在“用户管理”中：

- 新增普通用户，并设置初始用户名、密码、显示名称和邮箱；
- 查看用户角色、资料和注册时间；
- 删除普通用户。

删除用户前需要二次确认。删除后，该用户的登录会话、个人设置、阅读/收藏状态和讨论关联数据也会一起清理；最高管理员账户受到保护，不能从这里删除。

### 内容概览

管理中心还会显示文献总量、摘要和翻译覆盖情况、注册账户数量、讨论数量以及各期刊的文献分布，方便管理员判断内容是否完整。

## 常见问题

### 为什么打开网页后仍然看不到内容？

必须先输入有效的网页通行证。若通行证已过期或站点管理员更换了通行证，请重新获取最新通行证。

### 为什么不能收藏或标记已读？

这些操作属于个人数据功能，游客只能浏览。请到“游客账户”登录个人账户后再操作。

### 为什么切换期刊后仍然看到“补全”提示？

已保存的内容会立即展示，提示只针对当前页面缺少的摘要、关键词或翻译。后台补全结束后，页面会更新结果；不需要重复等待已经存在的内容。

### 为什么翻译没有马上出现？

翻译需要等待处理，或原文暂时没有可翻译的摘要。可以稍后重试；如果管理员批量任务也报告失败，请通过原文链接查看论文。

### 为什么从另一台设备登录后，原来的设备退出了？

同一个个人账户同一时间只能绑定一个 IP。请在当前设备重新登录，或者先在原设备退出账户。

### 个人账户和网页通行证是不是同一个账号？

不是。网页通行证负责进入站点，个人账户负责保存个人数据和参与讨论，两者可以独立使用。

### 新手教程跳过了几步，是不是出问题了？

不是。教程对“当前状态下不适用”的步骤会自动跳过，并在提示区写明原因：未登录个人账户时会跳过“文献推送”一段；卡片阅读被关闭（例如按了 `Esc`）时会先自动重开，仍打不开才跳过阅读器内的步骤。需要重看时，到“使用说明”页点“重新体验新手教程”。

### 教程中途关掉了，怎么继续？

教程不记忆进度。到“使用说明”页点“重新体验新手教程”即可从头播放，跟着点一遍通常 3 分钟。

## 自托管部署（管理员）

本节面向自行部署本系统的管理员；日常使用者可以跳过。

### 环境要求与启动

- Node.js ≥ 22（依赖原生 `node:sqlite`）；
- `npm install` 安装依赖，`npm run build` 构建前端到 `dist/`，`npm start` 启动服务（默认端口 4177，同时提供 API 与构建产物）；
- 开发模式用 `npm run dev`（后端 4177 + Vite 5173 代理）。

### 必填环境变量

服务在仓库根目录读取 `.env`（模板见 `.env.example`）。以下三项**没有默认值，缺失时服务拒绝启动**——硬编码默认值曾在公开 git 历史中泄露，已于 2026-10-01 移除：

| 变量 | 说明 |
| --- | --- |
| `ADMIN_PASSPORT` | 管理员网页通行证（进入站点 + 打开管理中心） |
| `USER_PASSPORT` | 普通用户网页通行证 |
| `SUPER_ADMIN_USERNAME` | 最高管理员个人账户用户名 |

其余变量均为可选或带安全默认值，覆盖数据源密钥（IEEE / Elsevier / 翻译服务）、邮件 SMTP、推送计划等，逐项说明见 `.env.example` 注释。**任何通行证、密钥只保存在 `.env`（已被 .gitignore 排除），不要写进代码或文档。**

### 数据与维护

- 数据库为 `data/literature.sqlite`（SQLite，含文献、用户账户、会话等），`data/` 目录已被 .gitignore 排除，随部署独立备份；
- Windows 生产环境的计划任务、看门狗与部署脚本见 `DEPLOY.md`；
- AI 批量作业（研究方向分类、周报/月报/方向专报）由仓库根目录 `RUNBOOK-AI-JOBS.md` 与 `.workbuddy/skills/literature-ai-jobs/` 描述，是独立的定时执行流程，不参与服务进程。
